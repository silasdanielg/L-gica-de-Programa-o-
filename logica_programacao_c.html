1. O que é lógica de programação?

É a forma de organizar um problema em passos para que o computador consiga resolvê-lo.

Exemplo: pedir dois números → somá-los → mostrar o resultado.

2. Estrutura básica de um programa C

#include <stdio.h>

int main() {
    printf("Olá, mundo!");

    return 0;
}
  • #include <stdio.h> permite usar funções como printf e scanf.
  • main() é onde o programa começa.
  • printf() mostra informações na tela.
  • return 0 indica que o programa terminou normalmente.

4. Entrada de dados

Usamos scanf() para receber dados digitados pelo usuário.

int idade;

printf("Digite sua idade: ");
scanf("%d", &idade);

printf("Você tem %d anos.", idade);
FormatoTipo

6. Condições — if e else

Permitem que o programa tome decisões.

int idade = 16;

if (idade >= 18) {
    printf("Maior de idade");
} else {
    printf("Menor de idade");
}
OperadorSignificado
==Igual
!=Diferente
>Maior
<Menor
>=Maior ou igual
<=Menor ou igual

⚠️ = atribui um valor; == compara valores.

7. Repetições

for

for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}

Resultado: 1, 2, 3, 4, 5.

while

int i = 1;

while (i <= 5) {
    printf("%d\n", i);
    i++;
}

8. Funções

Funções permitem separar o programa em partes reutilizáveis.

int soma(int a, int b) {
    return a + b;
}

int main() {
    int resultado = soma(5, 3);

    printf("%d", resultado);

    return 0;
}

A função soma() recebe dois números e retorna o resultado.

9. Arrays

Arrays armazenam vários valores em uma única variável.

int numeros[5] = {10, 20, 30, 40, 50};

printf("%d", numeros[0]);

⚠️ A contagem começa em 0:

numeros[0] → 10
numeros[1] → 20
numeros[2] → 30
numeros[3] → 40
numeros[4] → 50

10. Exemplo completo

Um programa que recebe dois números, soma e mostra o resultado:

#include <stdio.h>

int main() {
    int a, b, soma;

    printf("Digite dois números: ");
    scanf("%d %d", &a, &b);

    soma = a + b;

    printf("Resultado: %d", soma);

    return 0;
}
